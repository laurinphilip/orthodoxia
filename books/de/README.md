# Deutsche Bücher

Lade nur PDF-Dateien hoch, die du tatsächlich selbst veröffentlichen darfst. Achte auf die Rechte am Original, an der Übersetzung, an der konkreten Ausgabe und am bereitgestellten PDF.

Historische Ausgaben aus der Bibliothek der Kirchenväter: https://bkv.unifr.ch/about/copyrights

Beispiel: Lade eine zulässig verwendbare PDF-Datei mit dem Namen `athanasius-menschwerdung.pdf` in diesen Ordner hoch. Ergänze anschließend beim passenden Buch in `js/library.js`:

```js
localPdf: "./books/de/athanasius-menschwerdung.pdf",
```

Die Bibliothek verwendet dann deine lokal hochgeladene Datei anstelle des externen PDF-Links. Die ursprüngliche Quelle bleibt weiterhin separat verlinkt.
