# English books

Only upload PDF files that you are actually entitled to redistribute. Check the original work, translation, edition, PDF file, and any licence conditions separately.

Project Gutenberg redistribution terms: https://www.gutenberg.org/license

Example: Upload a properly redistributable file named `john-damascus-holy-images.pdf` into this folder. Then add the following property to its matching book inside `js/library.js`:

```js
localPdf: "./books/en/john-damascus-holy-images.pdf",
```

Keep any required licence and source notices. The library will prefer your uploaded local file while continuing to show the original source link.
